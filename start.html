Python с нуля

Семь коротких уроков для тех, кто никогда не программировал. Код запускается прямо на этой странице: нажимайте «Запустить», меняйте его и запускайте снова. Ошибиться не страшно, ничего не сломается.

При первом запуске браузер загружает Python, это займёт несколько секунд. Незнакомые слова есть в словаре.

0 из 7 уроков пройдено

  1. Урок 1. Первая программа

    Программа — это список команд для компьютера. Он выполняет их по очереди, сверху вниз.

    Команда print выводит текст на экран. Сам текст всегда пишут в кавычках.

    Попробуйте: напишите в кавычках своё имя и нажмите «Запустить».

    Ваша программа
    print("Привет!")
print("Это моя первая программа")

  2. Урок 2. Переменные: как запомнить значение

    Переменная — это подпись на коробке. В коробку кладут значение, а потом обращаются к нему по имени.

    Со значениями можно работать: например, прибавить к возрасту единицу.

    Попробуйте: поставьте своё имя и возраст и запустите снова.

    Ваша программа
    name = "Аня"
age = 18

print("Меня зовут", name)
print("Через год мне будет", age + 1)

  3. Урок 3. Условия: если так, то вот так

    Программа умеет выбирать. Слово if значит «если», а else значит «иначе».

    Отступ из четырёх пробелов показывает, какие строки относятся к условию.

    Попробуйте: поменяйте температуру на 10 и посмотрите, что изменится.

    Ваша программа
    temperature = -5

if temperature < 0:
    print("На улице мороз, наденьте шапку")
else:
    print("Можно без шапки")

  4. Урок 4. Списки и циклы: одно действие много раз

    Список хранит несколько значений подряд. Цикл for берёт их по одному и делает с каждым одно и то же.

    Так сайт показывает ленту: у него есть список записей, и он выводит их одну за другой.

    Попробуйте: добавьте в список своё дело.

    Ваша программа
    tasks = ["купить хлеб", "сделать уроки", "позвонить маме"]

for task in tasks:
    print("Сделать:", task)

print("Всего дел:", len(tasks))

  5. Урок 5. Функции: своя команда

    Функция — это ваша собственная команда. Её описывают один раз, а вызывают сколько угодно.

    Слово def начинает описание, а return говорит, что функция отдаёт обратно.

    Попробуйте: вызовите функцию ещё раз с другим именем.

    Ваша программа
    def greet(name):
    return "Привет, " + name + "!"

print(greet("Аня"))
print(greet("Марат"))

  6. Урок 6. Словари: найти значение по названию

    Словарь хранит пары «название и значение», как прайс-лист в магазине. Значение находят по названию, а не по номеру.

    Сайты пользуются этим постоянно: например, находят страницу по её адресу.

    Попробуйте: добавьте свой товар с ценой.

    Ваша программа
    prices = {"хлеб": 200, "молоко": 450}

print("Хлеб стоит", prices["хлеб"], "тенге")

prices["сыр"] = 1500
print(prices)

  7. Урок 7. Как это связано с сайтами

    Вы уже знаете всё, чтобы понять главное. Адрес в браузере выбирает функцию, а функция возвращает страницу.

    Ниже маленький сайт, собранный из того, что вы только что прошли: функций и словаря.

    Второй пример делает то же самое на Flask. Это готовый инструмент для сайтов: строка @app.route говорит, какой адрес открывает эту функцию.

    Попробуйте: поменяйте адрес на "/" и запустите снова.

    Сайт из функций и словаря
    def home():
    return "Главная страница"

def contacts():
    return "Наши контакты"

pages = {"/": home, "/contacts": contacts}

address = "/contacts"
print("Вы открыли:", address)
print("Сайт ответил:", pages[address]())
    То же самое на Flask
    from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Главная страница"

print("Сайт ответил:", app.test_client().get("/").text)
