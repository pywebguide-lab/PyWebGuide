Басты бет / Нөлден

Python нөлден

Бұрын ешқашан бағдарлама жазбағандарға арналған жеті қысқа сабақ. Код дәл осы бетте іске қосылады: «Іске қосу» батырмасын басыңыз, кодты өзгертіп, қайта іске қосыңыз. Қателесуден қорықпаңыз, ештеңе бұзылмайды.

Алғаш іске қосқанда браузер Python-ды жүктейді, бұл бірнеше секундқа созылады. Бейтаныс сөздер сөздікте бар (әзірге орыс тілінде).

7 сабақтың 0 сабағы өтілді

  1. 1-сабақ. Алғашқы бағдарлама

    Бағдарлама — компьютерге арналған командалар тізімі. Ол оларды жоғарыдан төменге қарай кезекпен орындайды.

    print командасы мәтінді экранға шығарады. Мәтіннің өзі әрқашан тырнақшаға алынып жазылады.

    Байқап көріңіз: тырнақшаның ішіне атыңызды жазып, «Іске қосу» батырмасын басыңыз.

    Сіздің бағдарламаңыз
    print("Сәлем!")
print("Бұл менің алғашқы бағдарламам")

  2. 2-сабақ. Айнымалылар: мәнді қалай есте сақтау

    Айнымалы — қораптағы жазу сияқты. Қорапқа мән салынады, содан кейін оған аты арқылы жүгінеді.

    Мәндермен жұмыс істеуге болады: мысалы, жасқа бір қосу.

    Байқап көріңіз: өз атыңыз бен жасыңызды қойып, қайта іске қосыңыз.

    Сіздің бағдарламаңыз
    name = "Аружан"
age = 18

print("Менің атым", name)
print("Келесі жылы:", age + 1, "жас")

  3. 3-сабақ. Шарттар: егер былай болса, онда былай

    Бағдарлама таңдау жасай алады. if сөзі «егер», ал else «әйтпесе» дегенді білдіреді.

    Төрт бос орыннан тұратын шегініс қай жолдардың шартқа жататынын көрсетеді.

    Байқап көріңіз: температураны 10-ға өзгертіп, не өзгеретінін қараңыз.

    Сіздің бағдарламаңыз
    temperature = -5

if temperature < 0:
    print("Далада аяз, бөрігіңізді киіңіз")
else:
    print("Бөріксіз де болады")

  4. 4-сабақ. Тізімдер мен циклдер: бір әрекетті көп рет

    Тізім бірнеше мәнді қатарынан сақтайды. for циклі оларды бір-бірден алып, әрқайсысымен бірдей әрекет жасайды.

    Сайт лентаны осылай көрсетеді: оның жазбалар тізімі бар, ол оларды бірінен соң бірін шығарады.

    Байқап көріңіз: тізімге өз ісіңізді қосыңыз.

    Сіздің бағдарламаңыз
    tasks = ["нан сатып алу", "сабақ оқу", "анама қоңырау шалу"]

for task in tasks:
    print("Істеу керек:", task)

print("Барлық іс:", len(tasks))

  5. 5-сабақ. Функциялар: өз командаңыз

    Функция — сіздің жеке командаңыз. Оны бір рет сипаттайды, ал қанша рет болса да шақыра береді.

    def сөзі сипаттаманы бастайды, ал return функцияның не қайтаратынын айтады.

    Байқап көріңіз: функцияны басқа атпен тағы бір рет шақырыңыз.

    Сіздің бағдарламаңыз
    def greet(name):
    return "Сәлем, " + name + "!"

print(greet("Аружан"))
print(greet("Марат"))

  6. 6-сабақ. Сөздіктер: мәнді атауы бойынша табу

    Сөздік «атау мен мән» жұптарын дүкендегі баға тізімі сияқты сақтайды. Мәнді нөмірі бойынша емес, атауы бойынша табады.

    Сайттар мұны үнемі пайдаланады: мысалы, бетті оның мекенжайы бойынша табады.

    Байқап көріңіз: өз тауарыңызды бағасымен қосыңыз.

    Сіздің бағдарламаңыз
    prices = {"нан": 200, "сүт": 450}

print("Нанның бағасы", prices["нан"], "теңге")

prices["ірімшік"] = 1500
print(prices)

  7. 7-сабақ. Мұның сайттарға қандай қатысы бар

    Ең бастысын түсіну үшін сіз бәрін біліп қойдыңыз. Браузердегі мекенжай функцияны таңдайды, ал функция бетті қайтарады.

    Төменде сіз жаңа ғана өткен нәрселерден — функциялар мен сөздіктен жасалған шағын сайт тұр.

    Екінші мысал дәл осыны Flask-та жасайды. Бұл сайттарға арналған дайын құрал: @app.route жолы осы функцияны қай мекенжай ашатынын айтады.

    Байқап көріңіз: мекенжайды "/" деп өзгертіп, қайта іске қосыңыз.

    Функциялар мен сөздіктен жасалған сайт
    def home():
    return "Басты бет"

def contacts():
    return "Біздің байланыс деректеріміз"

pages = {"/": home, "/contacts": contacts}

address = "/contacts"
print("Сіз аштыңыз:", address)
print("Сайт жауап берді:", pages[address]())
    Дәл осы Flask-та
    from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Басты бет"

print("Сайт жауап берді:", app.test_client().get("/").text)

Әрі қарай не бар

Енді сіз негізді түсінесіз. Әрі қарай сұрау нағыз сервер арқылы қалай өтетінін біліп, алғашқы сайтыңызды жасайсыз. Бұл бөлімдер әзірге орыс тілінде.
