Git: история вашего проекта

Git запоминает версии кода, позволяет вернуться к рабочему состоянию и работать вместе. GitHub — сайт, где хранят копии таких проектов.

Первый коммит

Коммит — сохранённый снимок проекта с понятным описанием.

Терминал: один раз на компьютере 
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
Терминал: в папке проекта 
git init
git status
git add app.py
git commit -m "Добавить главную страницу"
git log --oneline

Три состояния файла

  1. Изменён: вы поправили файл, но Git его ещё не сохранил.
  2. Подготовлен: команда git add добавила его в будущий коммит.
  3. Сохранён: команда git commit записала снимок в историю.

Что не нужно хранить в Git

Файл .gitignore перечисляет то, что Git не должен отслеживать.

.gitignore 
.venv/
__pycache__/
*.db
db.sqlite3
.env

Если пароль или ключ уже попал в коммит на GitHub, простого удаления файла мало: он останется в истории. Считайте ключ раскрытым и замените его на новый.

Ветки

Ветка позволяет сделать новую функцию отдельно и не ломать рабочую версию.

Терминал 
git switch -c search-form
git add .
git commit -m "Добавить форму поиска"
git switch main
git merge search-form
git branch -d search-form

Если возник конфликт

Конфликт значит, что две ветки изменили одну и ту же строку. Откройте файл, оставьте нужный вариант, удалите метки <<<<<<<, ======= и >>>>>>>, затем выполните git add и git commit.

Работа с GitHub

Сначала создайте пустой репозиторий на github.com.

Терминал: первая отправка 
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
Терминал: обычный день 
git pull
git add .
git commit -m "Исправить форму входа"
git push

Как отменить изменения

Перед отменой посмотрите на текущее состояние через git status.

Что делать в разных ситуациях
СитуацияКомандаВажно
Убрать файл из подготовленныхgit restore --staged app.pyПравки в файле останутся
Отменить правки в файлеgit restore app.pyНесохранённые правки пропадут навсегда
Отменить уже отправленный коммитgit revert abc1234Создаёт новый коммит, история не ломается
Исправить текст последнего коммитаgit commit --amendТолько если коммит ещё не отправлен

Команды git reset --hard и git push --force могут безвозвратно удалить работу. Новичку лучше обойтись без них.

Хороший текст коммита

Описывайте, что изменилось и зачем. Через месяц вы будете читать историю как дневник проекта.

Понятно

  • Добавить проверку пустой задачи
  • Исправить вход с неверным паролем

Непонятно

  • правки
  • fix
  • ещё раз
