ЗАПУСК
  Откройте index.html в браузере (Chrome, Edge, Firefox).
  Сервер не нужен. Файлы должны лежать вместе, в той же структуре:

    index.html                — главная, дорожная карта с прогрессом
    about.html                — О Python
    frameworks.html           — Django, Flask, FastAPI, мини-тест
    databases.html            — SQL, SQLite, ORM и миграции Django
    project.html              — первый проект по шагам (Flask и Django), частые ошибки
    deploy.html               — публикация на PythonAnywhere
    404.html                  — страница «не найдено» для GitHub Pages
    contacts.html             — форма обратной связи, об авторах
    privacy.html              — политика конфиденциальности
    terms.html                — условия использования
    styles.css                — оформление и медиазапросы
    script.js                 — меню, мини-тест, прогресс, форма
    assets/knowledge-map.svg  — схема пути запроса
    assets/icon.svg, *.png    — иконки сайта и картинка превью для мессенджеров
    sitemap.xml               — карта сайта для поисковых систем

  Старые адреса ЛР3 (#/about, #/frameworks, #/contacts) перенаправляются
  на отдельные страницы.

ОГРАНИЧЕНИЯ
  - Для запуска Python нужен интернет: браузер загружает Pyodide с jsDelivr, а Flask с PyPI.
  - Примеры на Python учебные: сервер в проекте не запускается.
  - Форма «Контакты» открывает новую запись в GitHub Issues: нужен аккаунт
    GitHub, сообщение будет видно всем. Копия хранится в localStorage
    (ключ pyweb_messages) и удаляется кнопкой «Очистить сохранённые сообщения».
  - Кнопка «Копировать» использует Clipboard API; при открытии
    через file:// браузер может запретить копирование.
