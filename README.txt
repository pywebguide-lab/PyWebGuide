PyWeb Guide — учебный веб-ресурс о Python в веб-разработке
ЛР3, «Введение в веб-дизайн и разработку», ИСУ(СОП)-25
Авторы: Жангужин Е. Е., Косяк Р. А.

ЗАПУСК
  Откройте index.html в браузере (Chrome, Edge, Firefox).
  Сервер не нужен. Файлы должны лежать вместе, в той же структуре:

    index.html                — разметка, четыре логических раздела
    styles.css                — оформление и медиазапросы
    script.js                 — маршруты, меню, мини-тест, учебная форма
    assets/knowledge-map.svg  — схема пути запроса

РАЗДЕЛЫ (hash-навигация)
  #/            Главная
  #/about       О Python
  #/frameworks  Фреймворки (сравнение, таблицы, мини-тест)
  #/contacts    Контакты (учебная форма)
  Неизвестный адрес открывает главную.

ОГРАНИЧЕНИЯ
  - Примеры на Python учебные: сервер в проекте не запускается.
  - Форма «Контакты» ничего не отправляет. Сообщения сохраняются
    только в localStorage этого браузера (ключ pyweb_messages)
    и удаляются кнопкой «Очистить сохранённые сообщения».
  - Кнопка «Копировать» использует Clipboard API; при открытии
    через file:// браузер может запретить копирование.
