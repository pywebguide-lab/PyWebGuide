Авторы: Жангужин Е. Е., Косяк Р. А.

ЗАПУСК
  Откройте index.html в браузере (Chrome, Edge, Firefox).
  Сервер не нужен. Файлы должны лежать вместе, в той же структуре:

    index.html                — главная, дорожная карта с прогрессом
    about.html                — О Python
    frameworks.html           — Django, Flask, FastAPI, мини-тест
    project.html              — первый проект по шагам (Flask и Django)
    contacts.html             — учебная форма, об авторах
    styles.css                — оформление и медиазапросы
    script.js                 — меню, мини-тест, прогресс, учебная форма
    assets/knowledge-map.svg  — схема пути запроса
    sitemap.xml               — карта сайта для поисковых систем

  Старые адреса ЛР3 (#/about, #/frameworks, #/contacts) перенаправляются
  на отдельные страницы.

ДОРАБОТКА ПО ИТОГАМ ЛР4 (план совершенствования, табл. 10.3 отчета)
  - раздел «Первый проект»: список задач на Flask и на Django по шагам;
  - блок «Источники» с документацией и версиями на каждой странице;
  - блок «Об авторах», дата обновления и версии в подвале;
  - персональная рекомендация с переходом к практике после мини-теста;
  - отметки пройденных шагов (localStorage, ключ pyweb_progress);
  - отдельные HTML-страницы со своими title, description, canonical;
  - краткий раздел о FastAPI;
  - исправлены замечания Lighthouse (порядок заголовков, имя ссылки-логотипа).

ОГРАНИЧЕНИЯ
  - Примеры на Python учебные: сервер в проекте не запускается.
  - Форма «Контакты» ничего не отправляет. Сообщения сохраняются
    только в localStorage этого браузера (ключ pyweb_messages)
    и удаляются кнопкой «Очистить сохранённые сообщения».
  - Кнопка «Копировать» использует Clipboard API; при открытии
    через file:// браузер может запретить копирование.
