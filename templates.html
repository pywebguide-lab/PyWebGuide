Главная / Шаблоны и формы

Как сервер строит страницы

Шаблон — это HTML с местами для данных. Форма — способ получить данные от пользователя. Разберём оба механизма; примеры с кнопкой «Запустить» выполняются прямо в браузере.

Шаблоны Jinja

Flask использует Jinja, а язык шаблонов Django очень на него похож.

  • {{ значение }} выводит данные и автоматически экранирует HTML.
  • {% if %} и {% for %} добавляют условия и циклы.
  • {% extends %} и {% block %} дают общий каркас для всех страниц.
Flask: цикл и условие в шаблоне 
from flask import Flask, render_template_string

app = Flask(__name__)

PAGE = """
<h1>Задачи: {{ tasks|length }}</h1>
{% for task in tasks %}
  <p>{{ loop.index }}. {{ task.title }}{% if task.done %} (готово){% endif %}</p>
{% else %}
  <p>Задач пока нет</p>
{% endfor %}
"""

@app.route("/")
def index():
    tasks = [
        {"title": "Купить ракетку", "done": True},
        {"title": "Прочитать про шаблоны", "done": False},
    ]
    return render_template_string(PAGE, tasks=tasks)

print(app.test_client().get("/").text)

test_client() отправляет запрос приложению без настоящего сервера. Этим же способом пишут тесты.

Наследование шаблонов

Шапка и подвал описываются один раз, а страницы заменяют только свой блок.

templates/base.html 
<!doctype html>
<html lang="ru">
<head><title>{% block title %}Сайт{% endblock %}</title></head>
<body>
  <nav><a href="/">Главная</a></nav>
  {% block content %}{% endblock %}
</body>
</html>
templates/index.html 
{% extends "base.html" %}

{% block title %}Задачи{% endblock %}

{% block content %}
  <h1>Мои задачи</h1>
{% endblock %}

Во Flask файлы лежат в папке templates, а страницу возвращает render_template("index.html"). В Django то же самое делает render(request, "index.html").

Почему экранирование важно

Если вывести текст пользователя как есть, он сможет вставить на страницу свой скрипт. Это называется XSS.

Экранирование и опасный фильтр safe 
from flask import Flask, render_template_string, request

app = Flask(__name__)

@app.route("/")
def index():
    name = request.args.get("name", "гость")
    safe = render_template_string("<p>{{ name }}</p>", name=name)
    danger = render_template_string("<p>{{ name|safe }}</p>", name=name)
    return f"Правильно: {safe}\nОпасно:    {danger}"

response = app.test_client().get("/", query_string={"name": "<script>alert(1)</script>"})
print(response.text)

Фильтр |safe отключает защиту. Используйте его только для HTML, который написали сами.

Формы во Flask

Данные формы лежат в request.form. Сервер обязан проверять их сам: проверки в браузере легко обойти.

Flask: проверка данных формы 
from flask import Flask, redirect, render_template_string, request, url_for

app = Flask(__name__)
tasks = []

PAGE = """
{% if error %}<p>{{ error }}</p>{% endif %}
<form method="post"><input name="title"><button>Добавить</button></form>
<ul>{% for task in tasks %}<li>{{ task }}</li>{% endfor %}</ul>
"""

@app.route("/", methods=["GET", "POST"])
def index():
    error = None
    if request.method == "POST":
        title = request.form.get("title", "").strip()
        if not title:
            error = "Введите название"
        elif len(title) > 100:
            error = "Слишком длинное название"
        else:
            tasks.append(title)
            return redirect(url_for("index"))
    return render_template_string(PAGE, tasks=tasks, error=error)

client = app.test_client()
print("Пустая форма:", "Введите название" in client.post("/", data={"title": " "}).text)
response = client.post("/", data={"title": "Первая задача"})
print("После добавления статус:", response.status_code, "переход на", response.location)
print("Задачи:", tasks)

После успешного POST отправляйте редирект. Иначе при обновлении страницы браузер повторит отправку и задача добавится ещё раз.

Защита от CSRF

Чужой сайт может незаметно отправить форму от имени вошедшего пользователя. Защита — секретный токен в каждой форме.

Django

Защита включена по умолчанию. В каждую форму с POST нужно добавить тег {% csrf_token %}, иначе сервер ответит ошибкой 403.

Flask

Встроенной защиты нет. Обычно подключают расширение Flask-WTF: CSRFProtect(app) и скрытое поле с токеном в форме.

Формы в Django

Класс формы описывает поля, проверяет данные и умеет выводить себя в HTML.

tasks/forms.py 
from django import forms

class TaskForm(forms.Form):
    title = forms.CharField(label="Задача", max_length=100)
tasks/views.py 
from django.shortcuts import redirect, render

from .forms import TaskForm
from .models import Task

def index(request):
    form = TaskForm(request.POST or None)
    if form.is_valid():
        Task.objects.create(title=form.cleaned_data["title"])
        return redirect("index")
    return render(request, "index.html", {"form": form, "tasks": Task.objects.all()})
templates/index.html 
<form method="post">
  {% csrf_token %}
  {{ form.as_p }}
  <button>Добавить</button>
</form>
