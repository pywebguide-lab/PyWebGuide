Python прямо в браузере

Пишите код и нажимайте «Запустить». Ничего устанавливать не нужно: код выполняется на вашем устройстве и никуда не отправляется.

Редактор

Сочетание Ctrl+Enter запускает код. Черновик сохраняется в этом браузере.

Что важно знать

Песочница работает на Pyodide: это Python, собранный для браузера.

  • При первом запуске браузер скачает около 5 МБ с сервиса jsDelivr. Для примера с Flask дополнительно загружаются пакеты с PyPI.
  • Настоящий сервер здесь не запустить. Вместо него приложение Flask получает запросы через test_client().
  • input() в браузере не работает. Задавайте значения прямо в коде.
  • Код останавливается через 10 секунд, поэтому бесконечный цикл не повесит страницу.
