Раздел 4

Первый проект: список задач

Сделаем одно и то же приложение — список задач — двумя способами: на Flask и на Django. Выберите один вариант и пройдите его до конца. В каждом две части: сначала простейший список, затем база данных, удаление и отметка «выполнено». На Flask уйдёт около 30 минут, на Django — около часа.

Вариант на Flask Вариант на Django

Что понадобится

Проверьте это до начала — так шаги пройдут без ошибок.

  • Python 3.12 или новее: команда python --version в терминале.
  • Редактор кода, например VS Code.
  • Отдельная пустая папка для проекта, открытая в терминале.
  • Базовый Python: функции, списки, словари (шаг 1 дорожной карты).

Команды для Windows. На macOS и Linux вместо python пишите python3, а виртуальное окружение активируйте командой source .venv/bin/activate. Отмеченные шаги сохраняются в этом браузере — можно вернуться позже и продолжить. Если что-то пошло не так, загляните в частые ошибки внизу страницы.

⚪ Flask 3.1 · ~30 минут

Вариант 1. Список задач на Flask

Одно приложение в одном файле: страница со списком и форма добавления задачи.

0 из 6 шагов пройдено

  1. Шаг 1. Создайте окружение и установите Flask

    Виртуальное окружение хранит библиотеки проекта отдельно от остальной системы.

    Терминал 
    python -m venv .venv
.venv\Scripts\activate
pip install flask

  2. Шаг 2. Напишите приложение

    Создайте файл app.py. Задачи пока хранятся в обычном списке — в памяти сервера.

    app.py 
    from flask import Flask, redirect, render_template_string, request, url_for

app = Flask(__name__)
tasks = []

PAGE = """
<!doctype html>
<title>Мои задачи</title>
<h1>Мои задачи</h1>
<form method="post">
  <input name="title" placeholder="Новая задача" required>
  <button>Добавить</button>
</form>
<ul>
  {% for task in tasks %}<li>{{ task }}</li>{% endfor %}
</ul>
"""

@app.route("/", methods=["GET", "POST"])
def index():
    if request.method == "POST":
        tasks.append(request.form["title"])
        return redirect(url_for("index"))
    return render_template_string(PAGE, tasks=tasks)

  3. Шаг 3. Запустите сервер

    Флаг --debug перезапускает сервер при каждом сохранении файла и показывает понятные ошибки.

    Терминал 
    flask --app app run --debug

  4. Шаг 4. Проверьте результат

    Откройте в браузере http://127.0.0.1:5000/ и добавьте пару задач. Обратите внимание: после перезапуска сервера список очищается — данные жили только в памяти. Сохранять их между запусками умеет база данных, это следующий шаг.

  5. Часть 2. База данных и удаление

    Шаг 5. Храните задачи в SQLite

    Замените весь app.py этим кодом. Модуль sqlite3 входит в Python, ничего устанавливать не нужно. Файл базы tasks.db появится рядом с app.py при первом запуске. Знаки ? в запросах — параметры: Python сам безопасно подставит значения, поэтому ввод пользователя не сможет изменить сам SQL-запрос. Подробнее — в разделе «Базы данных».

    app.py 
    import sqlite3
from pathlib import Path

from flask import Flask, redirect, render_template_string, request, url_for

app = Flask(__name__)
DB = Path(__file__).with_name("tasks.db")

PAGE = """
<!doctype html>
<title>Мои задачи</title>
<h1>Мои задачи</h1>
<form method="post" action="{{ url_for('add') }}">
  <input name="title" placeholder="Новая задача" required>
  <button>Добавить</button>
</form>
<ul>
  {% for task in tasks %}
    <li>
      {{ task["title"] }}
      <form method="post" action="{{ url_for('delete', task_id=task['id']) }}">
        <button>Удалить</button>
      </form>
    </li>
  {% endfor %}
</ul>
"""

def query(sql, params=()):
    conn = sqlite3.connect(DB)
    conn.row_factory = sqlite3.Row
    try:
        rows = conn.execute(sql, params).fetchall()
        conn.commit()
        return rows
    finally:
        conn.close()

query("CREATE TABLE IF NOT EXISTS tasks (id INTEGER PRIMARY KEY, title TEXT NOT NULL)")

@app.get("/")
def index():
    tasks = query("SELECT id, title FROM tasks ORDER BY id")
    return render_template_string(PAGE, tasks=tasks)

@app.post("/add")
def add():
    query("INSERT INTO tasks (title) VALUES (?)", (request.form["title"],))
    return redirect(url_for("index"))

@app.post("/delete/<int:task_id>")
def delete(task_id):
    query("DELETE FROM tasks WHERE id = ?", (task_id,))
    return redirect(url_for("index"))

  6. Шаг 6. Проверьте, что данные сохраняются

    Запустите сервер той же командой, добавьте пару задач и удалите одну. Затем остановите сервер (Ctrl + C) и запустите снова — задачи останутся на месте. Удаление сделано через POST, а не обычную ссылку: изменяющие данные действия не должны выполняться простым переходом по адресу.

Что дальше

  • Вынесите HTML в шаблон templates/index.html и используйте render_template.
  • Добавьте отметку «выполнено»: колонка done INTEGER DEFAULT 0 и запрос UPDATE.
  • Опубликуйте приложение в интернете — инструкция в разделе «Публикация».
🟢 Django 6.1 · ~60 минут

Вариант 2. Список задач на Django

Задачи хранятся в базе данных SQLite, а добавлять их можно через встроенную админ-панель.

0 из 10 шагов пройдено

  1. Шаг 1. Установите Django и создайте проект

    Точка в конце команды создаёт проект в текущей папке. Затем создаём приложение tasks.

    Терминал 
    python -m venv .venv
.venv\Scripts\activate
pip install django
django-admin startproject mysite .
python manage.py startapp tasks

  2. Шаг 2. Подключите приложение

    В файле mysite/settings.py добавьте строку 'tasks', в конец списка INSTALLED_APPS.

    mysite/settings.py 
    INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'tasks',
]

  3. Шаг 3. Опишите модель и зарегистрируйте её в админке

    Модель — это таблица базы данных, описанная классом Python. ORM сама создаст для неё SQL.

    tasks/models.py 
    from django.db import models

class Task(models.Model):
    title = models.CharField(max_length=200)
    done = models.BooleanField(default=False)

    def __str__(self):
        return self.title
    tasks/admin.py 
    from django.contrib import admin

from .models import Task

admin.site.register(Task)

  4. Шаг 4. Создайте таблицы и администратора

    Миграции переносят модели в базу данных. Последняя команда спросит логин и пароль для входа в админку.

    Терминал 
    python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser

  5. Шаг 5. Сделайте страницу со списком

    Представление получает задачи из базы, шаблон выводит их списком, маршрут связывает адрес с представлением. Шаблон положите в папку tasks/templates/tasks/ — Django найдёт его сам.

    tasks/views.py 
    from django.shortcuts import render

from .models import Task

def index(request):
    return render(request, "tasks/index.html", {"tasks": Task.objects.all()})
    tasks/templates/tasks/index.html 
    <h1>Мои задачи</h1>
<ul>
  {% for task in tasks %}
    <li>{{ task.title }}{% if task.done %} ✓{% endif %}</li>
  {% empty %}
    <li>Задач пока нет — добавьте их в админке.</li>
  {% endfor %}
</ul>
    mysite/urls.py 
    from django.contrib import admin
from django.urls import path

from tasks import views

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", views.index),
]

  6. Шаг 6. Запустите и проверьте

    Откройте http://127.0.0.1:8000/admin/, войдите и добавьте несколько задач. Затем откройте http://127.0.0.1:8000/ — задачи появятся в списке и сохранятся после перезапуска сервера.

    Терминал 
    python manage.py runserver

  7. Часть 2. Работа без админки

    Шаг 7. Создайте форму

    ModelForm строит форму прямо по модели: сама проверяет длину названия и сохраняет задачу в базу. Создайте новый файл tasks/forms.py.

    tasks/forms.py 
    from django import forms

from .models import Task

class TaskForm(forms.ModelForm):
    class Meta:
        model = Task
        fields = ["title"]

  8. Шаг 8. Добавьте представления и маршруты

    Замените tasks/views.py и mysite/urls.py целиком. Декоратор @require_POST разрешает менять данные только отправкой формы, а не переходом по ссылке. Имена маршрутов (name="index") нужны, чтобы ссылаться на них из шаблона.

    tasks/views.py 
    from django.shortcuts import get_object_or_404, redirect, render
from django.views.decorators.http import require_POST

from .forms import TaskForm
from .models import Task

def index(request):
    if request.method == "POST":
        form = TaskForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect("index")
    else:
        form = TaskForm()
    return render(request, "tasks/index.html", {"tasks": Task.objects.all(), "form": form})

@require_POST
def toggle(request, pk):
    task = get_object_or_404(Task, pk=pk)
    task.done = not task.done
    task.save()
    return redirect("index")

@require_POST
def delete(request, pk):
    get_object_or_404(Task, pk=pk).delete()
    return redirect("index")
    mysite/urls.py 
    from django.contrib import admin
from django.urls import path

from tasks import views

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", views.index, name="index"),
    path("tasks/<int:pk>/toggle/", views.toggle, name="toggle"),
    path("tasks/<int:pk>/delete/", views.delete, name="delete"),
]

  9. Шаг 9. Обновите шаблон

    Тег {% csrf_token %} обязателен в каждой форме с method="post": он защищает от подделки запросов с чужих сайтов. Без него Django ответит ошибкой 403.

    tasks/templates/tasks/index.html 
    <h1>Мои задачи</h1>

<form method="post">
  {% csrf_token %}
  {{ form.title }}
  <button>Добавить</button>
  {{ form.title.errors }}
</form>

<ul>
  {% for task in tasks %}
    <li>
      {% if task.done %}<s>{{ task.title }}</s>{% else %}{{ task.title }}{% endif %}
      <form method="post" action="{% url 'toggle' task.pk %}">
        {% csrf_token %}
        <button>{% if task.done %}Вернуть{% else %}Готово{% endif %}</button>
      </form>
      <form method="post" action="{% url 'delete' task.pk %}">
        {% csrf_token %}
        <button>Удалить</button>
      </form>
    </li>
  {% empty %}
    <li>Задач пока нет.</li>
  {% endfor %}
</ul>

  10. Шаг 10. Проверьте

    Запустите python manage.py runserver и откройте http://127.0.0.1:8000/. Добавьте задачу, отметьте её кнопкой «Готово» — она станет зачёркнутой, — затем удалите. Попробуйте добавить пустую задачу: форма покажет ошибку, а в базу ничего не попадёт. Миграции делать не нужно — модель не менялась.

Что дальше

  • Покажите сначала невыполненные задачи: Task.objects.order_by("done", "-id").
  • Пройдите официальное руководство Django — оно продолжает эту же логику на примере опросов.
  • Опубликуйте приложение в интернете — инструкция в разделе «Публикация».

Частые ошибки и как их исправить

Сообщения приведены так, как их показывают Windows, Flask и Django. Нажмите на ошибку, чтобы увидеть решение.

Команда python открывает Microsoft Store или пишет «Python was not found»

Python was not found; run without arguments to install from the Microsoft Store… Python не установлен или не добавлен в PATH, и Windows подставляет свою заглушку. Установите Python с python.org и отметьте пункт «Add python.exe to PATH». Если Python уже стоит, используйте команду py: py -m venv .venv. После активации окружения команда python заработает.

PowerShell не даёт активировать окружение: «выполнение сценариев отключено»

Невозможно загрузить файл …\.venv\Scripts\Activate.ps1, так как выполнение сценариев отключено в этой системе. В английской Windows: …Activate.ps1 cannot be loaded because running scripts is disabled on this system. Разрешите запуск локальных скриптов для своей учётной записи — один раз: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned. Другой вариант — открыть терминал «Командная строка» (cmd) вместо PowerShell.

«flask» или «django-admin» не распознано как имя командлета

Имя "flask" не распознано как имя командлета, функции, файла сценария или выполняемой программы. Окружение не активировано или пакет не установлен. Активируйте окружение (в начале строки терминала появится (.venv)) и повторите pip install flask или pip install django.

Django: «no such table: tasks_task»

django.db.utils.OperationalError: no such table: tasks_task Таблица для модели ещё не создана. Выполните шаг 4: python manage.py makemigrations и python manage.py migrate. Если команда пишет «No changes detected», проверьте, что 'tasks' добавлено в INSTALLED_APPS (шаг 2).

Django: «TemplateDoesNotExist at /»

TemplateDoesNotExist at / — tasks/index.html Django не нашёл шаблон. Путь должен быть точно таким: tasks/templates/tasks/index.html — папка tasks внутри templates повторяется намеренно. Также проверьте, что приложение есть в INSTALLED_APPS.

Django: «Forbidden (403) CSRF verification failed»

Forbidden (403) CSRF verification failed. Request aborted. В форме не хватает тега {% csrf_token %}. Он нужен в каждой форме с method="post" — сравните свой шаблон с шагом 9.
