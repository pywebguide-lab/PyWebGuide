Политика конфиденциальности

Коротко: у сайта нет своей базы данных. Отправленные через форму сообщения публикуются на GitHub и видны всем, а хостинг записывает IP-адреса посетителей.

Кто отвечает за сайт

PyWeb Guide — учебный проект. Автор: Жангужин Е. Е. Связаться с ним можно через раздел Issues на GitHub; сообщения там видны публично, поэтому не указывайте в них личные данные.

Что хранится в вашем браузере

Сайт использует localStorage — хранилище вашего браузера. На сервер эти записи не передаются, и автор их не видит:

  • pyweb_messages — копии сообщений из формы на странице «Контакты»;
  • pyweb_progress — отмеченные шаги обучения;
  • pyweb_theme — выбранная тема оформления;
  • pyweb_tasks и pyweb_task_* — решённые задачи и черновики решений;
  • pyweb_playground — черновик кода в песочнице;
  • pyweb_exam — лучший результат финального теста.

Сообщения удаляет кнопка «Очистить сохранённые сообщения» на странице «Контакты». Всё остальное можно удалить, очистив данные этого сайта в настройках браузера.

Что происходит при отправке формы

Форма открывает страницу создания записи в Issues на GitHub с вашим именем и текстом. Пока вы не подтвердите создание на GitHub, ничего не публикуется. После этого сообщение и ваш профиль GitHub видны всем, а обрабатывает их GitHub по своим правилам.

Что записывает хостинг

Сайт размещён на GitHub Pages. По данным GitHub, при посещении сайта IP-адрес посетителя записывается и хранится в целях безопасности. Источник — справка GitHub Pages, подробности — в политике конфиденциальности GitHub.

Запуск Python в браузере

Только после нажатия кнопки запуска или проверки кода браузер загружает Python (Pyodide) с сервиса jsDelivr, а для примеров с Flask ещё и пакеты с PyPI. Эти сервисы, как любой сайт, получают ваш IP-адрес и данные браузера. Сам код выполняется на вашем устройстве и никуда не отправляется. Имя для сертификата тоже остаётся в браузере и не сохраняется.

Cookies и аналитика

Сам сайт не устанавливает cookies и не подключает аналитику или рекламу.

Внешние ссылки

На сайте есть ссылки на документацию и другие внешние ресурсы. После перехода действуют правила этих ресурсов.

Изменения

При изменении политики мы обновим этот текст и дату в конце страницы.
