Шпаргалка

Самые частые команды на одной странице. Команды активации указаны для Windows; для macOS и Linux есть отдельная строка.

Окружение и пакеты

Для каждого проекта создавайте своё окружение.

Терминал 
python -m venv .venv
.venv\Scripts\activate         # Windows
source .venv/bin/activate      # macOS и Linux
pip install flask
pip freeze > requirements.txt
pip install -r requirements.txt
deactivate

Flask

Минимальное приложение и самые нужные функции.

Терминал 
flask --app app run --debug
flask --app app routes
app.py 
from flask import Flask, jsonify, redirect, render_template, request, url_for

app = Flask(__name__)

@app.route("/items/<int:item_id>", methods=["GET", "POST"])
def item(item_id):
    request.args.get("q")          # параметр адреса ?q=
    request.form.get("title")      # поле формы
    request.get_json(silent=True)  # тело JSON
    return render_template("item.html", item_id=item_id)

def examples():
    redirect(url_for("item", item_id=1))
    return jsonify([1, 2, 3]), 200

SQL

Основные запросы. Значения от пользователя передавайте только через параметры.

SQL 
SELECT id, title FROM tasks WHERE done = 0 ORDER BY id DESC LIMIT 10;
INSERT INTO tasks (title, done) VALUES ('Купить хлеб', 0);
UPDATE tasks SET done = 1 WHERE id = 5;
DELETE FROM tasks WHERE id = 5;
SELECT done, COUNT(*) FROM tasks GROUP BY done;
SELECT t.title, u.name FROM tasks t JOIN users u ON u.id = t.user_id;
