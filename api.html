REST API: сайт отдаёт данные

API нужен, когда сервер отвечает не страницей, а данными: сайту на JavaScript, мобильному приложению или другой программе.

Основные правила REST

Адрес обозначает данные, а метод HTTP — действие с ними.

Методы HTTP для списка задач
ЗапросЧто делаетУспешный ответ
GET /tasksВозвращает список200 OK
POST /tasksСоздаёт задачу201 Created
GET /tasks/5Возвращает одну задачу200 OK
PATCH /tasks/5Меняет часть полей200 OK
DELETE /tasks/5Удаляет204 No Content

Коды ответа

Клиент сначала смотрит на код и только потом читает тело ответа.

Всё хорошо или ошибка клиента

  • 200 — успешно
  • 201 — создано
  • 204 — успешно, тела ответа нет
  • 400 — неверные данные
  • 401 — нужно войти
  • 403 — нет прав
  • 404 — не найдено

Ошибка сервера

  • 500 — ошибка в коде приложения
  • 502 — веб-сервер не получил от приложения нормального ответа
  • 503 — сервис временно недоступен

Ошибка 5xx означает, что причину нужно искать на сервере, а не в запросе.

API на Flask

Flask сам превращает словарь в JSON. Список лучше передать через jsonify.

Flask: JSON API со списком задач 
from flask import Flask, jsonify, request

app = Flask(__name__)
tasks = {}
next_id = 1

@app.get("/tasks")
def list_tasks():
    return jsonify(list(tasks.values()))

@app.post("/tasks")
def create_task():
    global next_id
    data = request.get_json(silent=True) or {}
    title = str(data.get("title", "")).strip()
    if not title:
        return {"error": "Поле title обязательно"}, 400
    task = {"id": next_id, "title": title, "done": False}
    tasks[next_id] = task
    next_id += 1
    return task, 201

@app.patch("/tasks/<int:task_id>")
def update_task(task_id):
    task = tasks.get(task_id)
    if task is None:
        return {"error": "Задача не найдена"}, 404
    data = request.get_json(silent=True) or {}
    if "done" in data:
        task["done"] = bool(data["done"])
    return task

@app.delete("/tasks/<int:task_id>")
def delete_task(task_id):
    if tasks.pop(task_id, None) is None:
        return {"error": "Задача не найдена"}, 404
    return "", 204

client = app.test_client()
print(client.post("/tasks", json={}).status_code, "пустая задача")
created = client.post("/tasks", json={"title": "Написать API"})
print(created.status_code, created.json)
print(client.patch("/tasks/1", json={"done": True}).json)
print(client.get("/tasks").json)
print(client.delete("/tasks/1").status_code, "удалена")
print(client.delete("/tasks/1").status_code, "повторное удаление")

API на Django

Простой JSON-ответ можно отдать встроенными средствами. Для большого API обычно берут Django REST framework.

tasks/views.py 
import json

from django.http import JsonResponse
from django.views.decorators.csrf import csrf_exempt
from django.views.decorators.http import require_http_methods

from .models import Task

@csrf_exempt  # только для учебного примера: настоящему API нужна авторизация
@require_http_methods(["GET", "POST"])
def tasks(request):
    if request.method == "POST":
        try:
            data = json.loads(request.body)
            title = str(data.get("title", "")).strip()
        except (json.JSONDecodeError, AttributeError):
            return JsonResponse({"error": "Неверный JSON"}, status=400)
        if not title:
            return JsonResponse({"error": "Поле title обязательно"}, status=400)
        task = Task.objects.create(title=title)
        return JsonResponse({"id": task.id, "title": task.title}, status=201)
    return JsonResponse(list(Task.objects.values("id", "title")), safe=False)

Параметр safe=False нужен, потому что по умолчанию JsonResponse принимает только словарь.

Как вызвать API из браузера

На странице это делает функция fetch. Проверяйте код ответа: fetch не считает 404 ошибкой.

JavaScript 
async function addTask(title) {
  const response = await fetch("/tasks", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ title }),
  });

  if (!response.ok) {
    const problem = await response.json();
    throw new Error(problem.error);
  }

  return response.json();
}

Если сайт и API находятся на разных адресах, браузер заблокирует ответ, пока сервер не разрешит это заголовками CORS. Во Flask для этого есть расширение Flask-CORS.

Где здесь FastAPI

Если проект — только API, посмотрите на FastAPI: он проверяет данные по подсказкам типов и сам создаёт документацию. Принципы REST при этом те же.
